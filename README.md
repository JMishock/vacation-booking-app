# Vacation Booking Application

A full-stack vacation booking application built with **Java, Spring Boot, Hibernate, MySQL, and Angular**.

This application demonstrates a modern layered architecture using RESTful APIs, JPA/Hibernate persistence, and a relational database backend. Customers can browse vacation packages, manage reservations, and complete bookings through a web interface.

---

## Features

- Customer management
- Vacation package browsing
- Excursion management
- Shopping cart and checkout
- RESTful API endpoints
- MySQL database integration
- Spring Data JPA / Hibernate persistence
- Layered Spring Boot architecture
